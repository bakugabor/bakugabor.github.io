# Autofólie DS weboldal

Reszponzív, statikus bemutatkozó oldal szlovák nyelven. Nem igényel fizetős komponenst, adatbázist vagy szervert.

## Ingyenes publikálás

- **GitHub Pages:** töltsd fel a három weboldalfájlt (`index.html`, `style.css`, `script.js`) egy GitHub repository gyökerébe, majd a repository Settings → Pages részén válaszd a fő ágat.
- **Cloudflare Pages:** importáld a GitHub repository-t, a build command mezőt hagyd üresen, az output directory értéke legyen `/`.

## Személyre szabás publikálás előtt

A galériában a `placeholder-art` elemek helyére saját képek tehetők. A Facebook, Instagram és TikTok hivatkozások `@autofolie.ds` címre mutatnak. Ha van publikus telefonszám vagy e-mail-cím, az a kapcsolat szekcióhoz könnyen hozzáadható.
